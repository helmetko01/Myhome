# 헬코(Helko)의 마이홈 (Myhome)

단일 HTML(`index.html`)로 구현된 깔끔하고 반응형인 개인 홈페이지 겸 포트폴리오 웹사이트입니다.
별도의 빌드 도구나 외부 프레임워크 없이 웹 브라우저에서 즉시 열어 동작하는 가볍고 직관적인 웹 서비스입니다.

---

## 🌟 주요 섹션 및 기능

1. **헤더 & 히어로 (Hero)**
   - 실시간 날짜 및 시계 라이브 디스플레이
   - 따뜻한 소개 문구와 바로가기 CTA 버튼
   - 원클릭 라이트 / 다크 테마 전환 토글 (LocalStorage 동기화)

2. **소개 (About Me)**
   - 개인 프로필 및 지향하는 가치관(간결함, 실용성, 성장) 소개
   - 관심 기술 및 키워드 태그

3. **프로젝트 & 도구 (Projects & Tools)**
   - **⚡ 스마트 웹 계산기 (`calculator.html` / 내장 모달)**: 사칙연산, 부동소수점 오차 보정, 부호 반전, 퍼센트, 계산 내역 기능 내장
   - **📝 데일리 투두 플래너**: 실시간 할 일 추가/완료/삭제 (LocalStorage 연동)
   - **🐙 GitHub 저장소 연동**: [helmetko01/Myhome](https://github.com/helmetko01/Myhome)

4. **방명록 (Guestbook)**
   - 방문자가 메시지와 닉네임을 남길 수 있는 실시간 방명록 (LocalStorage 저장)

---

## 📁 파일 구성

- **`index.html`**: 단일 파일로 구성된 메인 개인 홈페이지 (HTML + CSS + Vanilla JS 내장)
- **`calculator.html`**: 단독 실행 가능한 스마트 웹 계산기 웹앱
- **`GEMINI.md`**: 프로젝트 개발 및 Git 자동화 워크플로 가이드
